
A pure function is a function that always returns the same output for the same input and does not produce any side effects.

An impure function is a function that produces side effects or does not always return the same output for the same input.

function currying :-Currying is a technique in JavaScript in which a function that takes multiple arguments is transformed into a sequence of functions, each taking one argument at a time.

shallow copy:- A shallow copy creates a new object, but nested objects and arrays are still shared between the original object and the copied object.

deep copy:-A deep copy creates a new object and recursively copies its nested objects and arrays, so that changes to the copied nested data do not affect the original data.

debouncing :-Debouncing is a technique that delays the execution of a function until a specified time has passed without another triggering event.

throttling:-Throttling is a technique that limits how frequently a function can execute within a specified time interval.


error handling :-Error handling is the process of detecting, catching, and managing errors in a program so that the application can handle unexpected situations gracefully.
